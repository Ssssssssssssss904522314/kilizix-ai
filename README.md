# Kilizix AI

Отдельный AI-проект с веб-интерфейсом на Flask. Ответы модели выполняются локально в браузере через WebLLM/WebGPU, поэтому для модели не нужен OpenAI API-ключ.

## Запуск

```bash
pip install -r requirements.txt
python app.py
```

## Render

Build Command:
`pip install -r requirements.txt`

Start Command:
`gunicorn app:app`

Дополнительные переменные окружения для локальной модели не требуются.

## Лимиты

Бесплатный режим: 15 запросов с 07:20 до 13:00 и 15 запросов с 15:50 до 00:00 по локальному времени устройства.

Premium план интерфейса: 150 ₽/год. Реальная платёжная интеграция подключается отдельно.
